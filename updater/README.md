# BR-A 자동 갱신 장치 — 1단계

## 무엇이 들어 있나요?
- `input/ritual.csv`: 날짜별 리추얼 행동과 평가, 관련 능력, 출처
- `input/tasks.csv`: 과제 코드·제목·확인 상태·날짜·출처
- `input/attendance.csv`: 날짜별 확정 출석 상태와 출처

**주의:** CSV는 구조 확인용 일부 예시입니다. 41일 전체 원본이나 완성된 자동 계산 데이터가 아닙니다. 현재 단계에는 Python 실행 파일이 없습니다.

## 초보자용 다음 순서
1. 이 폴더를 컴퓨터에 내려받습니다.
2. 비공개 기록은 `updater/private/`에 따로 보관합니다. 이 폴더는 .gitignore로 제외됩니다.
3. 다음 단계에서 예시 CSV를 전체 기록에서 추출한 익명·최소 데이터로 교체하고 Python 계산기를 제작합니다.

## 공개·비공개 구분
- 공개: 본인의 날짜·프로젝트·강점 행동에 관한 최소 정보와 집계 결과
- 비공개: 원본 리추얼·동료의 실명·제3자 연락처·개인 일화·비밀번호·토큰·API 키
- .gitignore는 **앞으로 새로 추가하는 파일**만 보호합니다. 이미 추적 중인 파일이나 예전 커밋에는 영향을 주지 않습니다.
- 기존 최상위 원본 리추얼 TXT/JSON, 출석 TXT, 소설 DOCX는 현재 공개 상태이므로 별도 정리 및 Git 기록 점검이 필요합니다.
- 원본을 안전하게 분리하기 전에는 GitHub에 새로운 민감정보를 커밋하지 마세요.

## 예정된 구현 (2~7단계)
CSV 집계 → 날짜/근거 포함 문단 후보 → 사람 승인 → 공개용 growth.json → 사이트 표시 → 동일 출력 SHA-256 비교 → ZIP 제출.
